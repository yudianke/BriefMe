# BriefMe · 今日简讯

*[English](README.en.md)*

把十几家中外媒体**过去 24 小时**的新闻抓回来，用 AI 分好类、写成摘要，
生成一个可以离线打开的网页。每天一条命令，五分钟看完天下事。
页面右上角可一键切换中文 / English。

```
首页                中国 Top5 / 国际 Top5（同一事件跨媒体合并，只占一个位置）
 ├─ 中国新闻        15 个分类的四列网格，左侧可按媒体筛选
 │   └─ 国际政治    AI 事件纪要 + 该分类全部报道（标题 / 摘要 / 原文链接）
 └─ 国际新闻        英文标题保留原文，下面附中文译题
```

---

## 快速开始

```bash
git clone <你的仓库地址>
cd briefme
pip install -r requirements.txt

cp .env.example .env      # Windows: copy .env.example .env
# 编辑 .env，填入任意一个 AI 服务的 key

python run.py
```

跑完会自动打开生成的网页。之后想再看，双击 `view.bat` 即可（不需要重跑）。

## 原理

整条流水线分五步，每步的产物都存进本地 SQLite，可以单独重跑：

| 步骤 | 做什么 | 说明 |
|---|---|---|
| **1. 抓取** | 拉 RSS / Google News / 少数站点直接解析 | 只取**标题、一小段摘要、原文链接**，不抓全文 |
| **2. 翻译** | 英文标题 → 中文译题 | 原标题保持不动，译题另存一列 |
| **3. 分类** | 每篇归 1–2 个分类 | 先看标题；标题看不出来才去读正文开头 |
| **4. 聚合** | 选出每个地区的 Top5 **事件** | 多家媒体报同一件事只算一个事件，来源越多排越前 |
| **5. 汇总 + 渲染** | 每个分类写一段事件纪要，生成静态 HTML | 纯静态页面，不需要服务器 |

几个设计取舍：

- **只保留 24 小时**：数据库长期存历史，但页面和 AI 输入一律只用最近 24 小时，
  以媒体的发布时间为准（不是抓取时间）。
- **时间存 UTC**：前端再转成你所在时区显示。
- **摘要预先算好**：不是点进去才现算，所以翻页是瞬间的，AI 花费也可控。
- **纯静态输出**：`output/` 里就是一堆 HTML，可以直接用浏览器打开、
  拷进 U 盘、或者丢到任何静态托管上。

## 配置 AI 服务

`.env` 里填**任意一个** key 就能跑。已内置 10 家，程序会自动挑第一个配好 key 的：

**中国大陆可直连**：DeepSeek、智谱 GLM、通义千问 Qwen、MiniMax
**境外**：ChatGPT、Gemini、Grok、Claude、Groq

想指定顺序就设 `AI_PROVIDERS=deepseek,qwen`（前面的当主用，失败自动退到后面）。

要加别的服务，在 `newsagg/ai.py` 的 `PROVIDERS` 里加一行即可 —— 只要对方提供
OpenAI 兼容接口，填上地址、环境变量名和模型名就行：

```python
"你的服务": Provider(
    name="你的服务",
    base_url="https://api.example.com/v1",
    api_key_env="YOUR_API_KEY",
    models={"default": "模型名"},
),
```

> 各家的模型名会变，如果报「模型不存在」，去对方文档查一下最新名字改掉即可。

## 运行模式

```bash
python run.py             # 完整跑一遍（调用 AI）
python run.py --cn-only   # 只抓国内源
python run.py --all       # 跳过联网探测，强制抓全部源
python run.py --no-ai     # 只抓取+渲染，不调用 AI
python run.py --manual    # 不花 API 额度，把 AI 任务交给 Claude Code 之类的助手做
python run.py --en        # 额外生成英文版 AI 内容（见下）
```

### 中文 / English 切换

页面右上角有个切换按钮，点一下整站换语言，选择会记住。分两层：

| | 需要 `--en` 吗 | 说明 |
|---|---|---|
| **界面文字** | 不需要 | 导航、按钮、分类名、媒体名、相对时间，全部内置双语，开箱即用 |
| **AI 生成的内容** | 需要 | 中文报道的英文译题、分类纪要、Top5 事件 |

没跑 `--en` 时切到英文，界面是英文的，AI 那部分回退显示中文——不会空白也不会报错。

`--en` 的做法是**把已生成的中文结果翻译成英文**，而不是用英文再跑一遍 AI。
这样中英两版讲的是同一批事件、同一个排序，切换语言不会看到两份对不上的榜单，
成本也低得多。代价是每次运行的 AI 调用量增加约 40%，所以默认不开。

> **原标题永远不会被替换。** 英文报道的主标题始终是英文原题，中文报道的主标题
> 始终是中文原题；译文只作为副标题出现，显示哪一种取决于当前界面语言。

### `--manual` 模式怎么用

适合手上没有 API 额度、但有 AI 编程助手的情况。**你只需要做两件事：**

**第 1 步 —— 你运行：**

```bash
python run.py --manual
```

抓取照常进行，只是不调用 AI，而是把待办写进 `manual/*.md`
（翻译、分类、Top5、纪要各一个文件，每个都写明了任务要求和输出格式）。

**第 2 步 —— 你对 AI 助手说：**

> 处理 manual 的待办

助手会读那几个 md 文件、把结果写成 `manual/results.json`，**并自己执行回写命令**。
完成后刷新网页即可。

---

<details>
<summary>如果助手只写了 results.json 却没回写（手动兜底）</summary>

自己敲这一条即可：

```bash
python -m newsagg.manual load manual/results.json && python -m newsagg.render
```

它做两件事：把 `results.json` 里的结果读进数据库（`load`），然后重新生成网页（`render`）。
正常流程里这条由助手代劳，你不需要记。

</details>

## 中国大陆使用说明

**不挂代理也能用，只是看不到境外媒体。**

程序启动时会先探测能否访问境外站点（走系统代理，和抓取同一条路）：

- **连得上** → 全部 20 个源正常抓
- **连不上** → 提示一句，自动跳过 14 个境外源，只抓 6 家国内媒体
  （新华社、央视新闻、财新、第一财经、参考消息、南方周末），页面照常生成

这么做是为了避免境外源逐个超时、把一轮抓取拖上几分钟。

**探测走的是和抓取完全相同的网络路径**（httpx + `trust_env`），所以：
环境变量代理、Windows 系统代理（Clash / v2rayN 最常见的模式）、
TUN 全局模式，这三种都能被正确识别，不会误拦。

万一还是误判了（比如代理特别慢、或分流规则把探测域名走了直连），
加 `--all` 跳过探测强制抓全部源：

```bash
python run.py --all
```

反过来，明知没有外网、想省掉探测那几秒，就用 `--cn-only`。

AI 服务同理：DeepSeek / GLM / Qwen / MiniMax 在大陆可直连，用它们就不需要代理。

## 加新的新闻源

编辑 `config/sources.yaml`：

```yaml
  - id: example                 # 唯一标识
    name: 示例日报               # 页面上显示的名字
    name_en: Example Daily      # 英文界面显示的名字（省略则回退用 name）
    region: china               # china 或 world
    lang: zh                    # zh 或 en（en 会自动生成中文译题）
    method: rss                 # rss / gnews / scrape
    feeds:
      - https://example.com/rss.xml
```

- `rss` —— 有 RSS 就优先用
- `gnews` —— RSS 坏了或没有，用 Google News 按 `site:` 查询兜底
- `scrape` —— 前两者都不行，在 `newsagg/scrapers.py` 写个专属解析函数

改完直接跑 `python run.py`，不用改其他代码。

## 目录结构

```
config/sources.yaml     新闻源清单（加源改这里）
newsagg/
  fetch.py              抓取 + 境外连通性探测
  scrapers.py           逐站解析（遵守 robots.txt）
  classify.py           分类      translate.py  翻译（外文 -> 中文）
  events.py             Top5 事件  summarize.py  分类纪要
  english.py            --en 模式：把中文结果译成英文
  render.py             生成静态站  ai.py        AI 服务注册表
  manual.py             --manual 模式的导出/回写
templates/              页面模板 + CSS + 前端脚本（i18n.js 管中英切换）
run.py                  一键入口      view.bat   打开已生成的网页
```

克隆下来时 `data/`、`output/`、`manual/`、`logos/` 都是空的 —— 这些是本地产物，
跑一次就有了。

## 权限与隐私

**不需要管理员权限**，普通用户直接 `python run.py` 就行，不会弹 UAC。

| | 说明 |
|---|---|
| **读取** | 系统代理设置（只读，仅当前用户）；你自己填在 `.env` 里的 API key |
| **写入** | 只写项目目录下的 `data/`、`output/`、`manual/`，不碰系统任何位置 |
| **联网** | 只连新闻站点，以及你在 `.env` 里配置的那家 AI 服务 |

**为什么会读系统代理**：判断"联网要不要走代理"。这一步由 `httpx` / `urllib`
标准库自动完成，本项目代码里没有主动调用；`pip`、`requests` 等常用工具走的是同一条路径。
在 Windows 上它读的是当前用户的 `Internet Settings`（也就是「Internet 选项」里那个代理框），
标准库的实现里只有查询、没有任何写操作。

**不做的事**：不修改系统设置或注册表、不启动子进程、不收集或上传你的本地数据。
抓来的新闻只存在你自己机器上。

**关于杀毒软件**：以源码形式运行的 `.py` 脚本一般不会被拦。如果你自行用
PyInstaller 之类打包成 `.exe`，可能碰上打包器常见的误报 —— 那是打包方式导致的，
和本项目代码无关。

代码不多，介意的话建议直接翻一遍 `newsagg/`，十几个文件，都是纯 Python。
